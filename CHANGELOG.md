# Changelog

## 0.1.1

- Compare with git HEAD now runs git only in a trusted folder, as the README and the Restricted Mode note say. In Restricted Mode the compare offers another file or the saved file, and git is not started.
- Each Zovo Pro tool now has 1 free try on your computer (was 3). After it, the next use opens the Zovo Pro panel, on any file. Escape, Cancel or an error uses no try. Nothing shows on open.
- Get Zovo Pro in the viewer's Pro row and the status bar goes straight to the card page; the Command Palette, footer and menus still open the Zovo Pro tab first. The license page's Open in VS Code button turns Pro on in one click.
- Prices and free features are unchanged.

## 0.1.0

- First release: binary, XML and OpenStep plists as an editable Key, Type and Value tree, saved in the format the file came in.
- Small plists such as an Info.plist open fully expanded; large ones open the first level and draw only the rows on screen.
- Readable names for known Info.plist, entitlements and profile keys; filter; copy as XML or JSON; Show XML; Save a Copy As XML, binary, JSON or OpenStep.
- Provisioning profiles open read-only; entitlements and privacy manifests open as plists.
- Zovo Pro tools with 3 free tries each: compare two plists, batch convert a folder, check Info.plist and profiles. Get Zovo Pro first shows what Pro includes and the tries left, in an editor tab.
- "More free viewers" starts with the Zovo extensions most related to this one; a link opens the Marketplace page, where you choose to install it. The walkthrough ends with the same links.
