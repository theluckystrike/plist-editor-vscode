# Edit like in Xcode

- Double-click a key or a value to change it. Enter saves the change, Escape cancels it.
- Click the type to pick another one. A value that fits the new type is kept: "42" becomes the number 42.
- `+` on a row adds an item below it, or inside it when it is an open dictionary or array. `-` deletes the row.
- Alt+Up and Alt+Down move a row. Ctrl+D (Cmd+D) duplicates it.
- Right-click a row to copy its key, its value, its key path, or the whole entry as XML or JSON.
- Undo and redo work as in any file, and nothing is written until you save.
